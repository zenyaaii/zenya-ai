# Zenya Theme Ultimate Section Guide

This document maps the **60+ standard sections** found in premium themes to the **Zenya Conversion Suite**. We have consolidated redundant sections into powerful, configurable archetypes while adding specialized "App-Killer" sections.

| Reference Section | Zenya Implementation | Purpose |
| :--- | :--- | :--- |
| **Header / Mega Menu** | `zenya-header` | Responsive navigation with mobile drawer. |
| **Footer** | `zenya-footer` | Site map, legal links, newsletter, social icons. |
| **Announcement Bar** | Integrated in Header | "Free Shipping" top bar. |
| **Breadcrumbs** | Integrated in Layout | SEO navigation path. |
