# Zenya AI — Canva Prompt Templates (MENA Psychology Series)

Reusable prompt structure for generating on-brand, emotionally-targeted social posts.
Copy the "Master Structure" once, then swap the bracketed variables for each new post.

---

## Master Structure (the anatomy of every prompt)

Every prompt should include these 5 parts, in this order:

1. **Format + platform** — "Arabic Instagram square post" / "Arabic Facebook post" / "Arabic Instagram Story vertical 9:16"
2. **Brand lock** — always paste this verbatim so colors never drift:
   `STRICT brand colors: cream #f7f4ed background, indigo #5e6ad2 accent, dark ink #1c1c1c text, border #e5e2d9, muted gray #6b6b6b.`
3. **Emotional theme** — one line naming the psychological angle (see the 4 below)
4. **Layout description** — where each text block sits, what's bold vs muted, what icon/divider appears
5. **Tone direction** — closing line like "Warm, conversational Arabic tone, premium editorial feel, generous whitespace"

## How to use these

1. Pick a template based on the emotion you want to trigger this week.
2. Swap only the bracketed variables — keep the brand-lock line and layout instructions untouched so every post stays visually consistent.
3. Paste the filled prompt into Canva's AI design generator (or ask Claude to generate it via the Canva connector).
4. Always request 4 variations per prompt and pick the strongest — the AI design tool returns design candidates, not a single final result.
